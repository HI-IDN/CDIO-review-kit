# Grading Workflow

## 1. Configure

Provide:

- assignment instructions;
- Canvas rubric;
- roster;
- GitHub Classroom assignment;
- module dates.

## 2. Fetch submissions

Retrieve all team repositories while preserving Git history and GitHub
metadata.

## 3. Compute basic analytics

Generate objective repository and collaboration indicators.

Do this before asking an LLM to interpret collaboration.

## 4. Procedural pass

Review procedural rubric requirements repo-by-repo.

Goal: obtain preliminary coverage of every submission quickly.

## 5. Cognitive passes

Take one substantial rubric criterion at a time.

Review it across all teams.

Establish anchor examples and check consistency.

## 6. Draft GitHub feedback

Have the agent create pending review comments.

The review remains unsubmitted.

## 7. Instructor checkpoint

The instructor:

- reads the provisional rubric;
- reads every proposed comment;
- deletes inappropriate comments;
- edits wording;
- checks questionable findings;
- decides what requires further investigation.

## 8. Prepare interview questions

Generate targeted questions from unresolved evidence.

## 9. Team assessment

Conduct the instructor-led oral/team assessment.

Use it to investigate understanding, engineering reasoning and collaboration
that could not be established from repository evidence.

## 10. Finalize

Update the assessment using all available evidence.

The instructor approves:

- rubric scores;
- individual adjustments;
- written feedback;
- submitted GitHub review;
- final grade.
