# Procedural Review

Review the assigned team's repository against all rubric criteria marked
`PROCEDURAL`.

Prioritize coverage.

For each criterion:

1. state whether the requirement is met;
2. cite concrete evidence;
3. identify missing or incorrect elements;
4. propose a provisional rubric result;
5. indicate uncertainty where appropriate.

Also identify obvious:

- broken code;
- missing files;
- reproducibility problems;
- incorrect paths;
- missing data;
- structural problems.

Do not spend substantial time on cognitive interpretation during this pass.

Create/update the team's preliminary review file.

Do not submit GitHub feedback.
